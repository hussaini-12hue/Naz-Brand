NAZ BRAND — REACT VERSION
========================

This is a React + Vite conversion of the uploaded NazBrandProject.
It keeps the shop's overall visual direction, page names, products and demo features,
and moves repeated layout elements into reusable React components.

PAGES
- index.html (Home)
- Products.html
- Categories.html
- Favorites.html
- Cart.html
- Login.html
- Dashboard.html
- Orders.html
- Customers.html
- Payments.html
- Account.html
- Profile.html
- Settings.html

RUN IN VS CODE
1. Install Node.js (LTS) from https://nodejs.org/
2. Extract this ZIP and open the NAZ-BRAND-REACT folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: npm install
5. Run: npm run dev
6. Open the local address Vite prints in the terminal.

BUILD
- npm run build

NOTES
- Cart and favorites use localStorage in the current browser.
- Login, checkout, payments and dashboard figures are demo/front-end only.
- This is not connected to a real backend, database, payment gateway or secure authentication.
- Product photos available in the original project were copied into public/assets.
- Existing project files were not modified; this React version is separate.
